========================================================================
GETTING STARTED: Lab 02_01, Debugging a Text Adventure Game
========================================================================

Lesson 2: Debugging with Claude. You start with a working text adventure
game, break it on purpose five times, and use Claude to find and fix
each problem.

FILES IN THIS FOLDER
  Lab Instructions.docx  Step-by-step lab instructions. Read first.
  adventure_game.py      The working starter program you will break and
                         fix.
  rooms.csv              The game's rooms and exits. Upload this.
  GETTING_STARTED.txt    This file.

GET THE FILES ONTO YOUR COMPUTER
If you are looking at this on GitHub, you need to download the files
before you can use them:
  - One file: click the file name, then click the download button
    (the small arrow icon labeled "Download raw file") near the top right.
  - Everything at once: go to the main page of the repository, click the
    green "Code" button, then "Download ZIP". Unzip it on your computer
    (on Windows: right-click > Extract All; on Mac: double-click it).

STEP 1: READ THE LAB INSTRUCTIONS FIRST
Open "Lab Instructions.docx" in this folder and read it all the way through
before you start. It explains the scenario, every step, and what you
need to hand in.
  - No Microsoft Word? Upload the file to Google Drive and open it with
    Google Docs, or open it for free at office.com.
  - Keep the instructions open in one window and Replit + Claude in
    another so you can follow along.

STEP 2: CREATE A NEW REPLIT PROJECT
  1. Go to replit.com and log in.
  2. Click "Create App" (it may say "+ Create" or "Create Repl").
     If Replit asks what you want to build with AI, choose the option to
     start from a template instead.
  3. Choose the "Python" template and name it lab-02-01-adventure-game.
  4. You should see a file called main.py and a green Run button.
  Use claude.ai for this lab, not Replit's built-in AI Agent. If Replit
  offers to write code for you, close that panel.

STEP 3: ADD THE STARTER CODE
Open adventure_game.py on your computer (any text editor works, e.g. Notepad
on Windows or TextEdit on Mac), copy all of it, and paste it into main.py in
Replit.
  How to paste code into main.py: open main.py, delete anything already
  in it, and paste. Only paste the code itself, not Claude's
  explanation text around it.

  When the Lab Instructions mention adventure_game.py, they mean the code
  that is now in your main.py.

STEP 4: UPLOAD THE DATA FILE
Upload rooms.csv to your Replit project. The code opens it by name, so do
not rename it.
  How to upload: in the Files panel on the left, click the three dots
  (...) and choose "Upload file", or drag the file from your computer
  into the Files panel. Make sure it ends up next to main.py, not inside
  another folder; the code finds files by name in that spot.

STEP 5: CHECK THE STARTING VERSION WORKS
Click Run. Play the game by typing directions until you see "You found the
treasure! You win!" (try: north, east, north).
  When the program asks you a question, click inside the Console panel,
  type your answer, and press Enter.
Before you start breaking things, paste your working code into a Claude
chat and label it "backup before lab breaks". If you get lost, you can
always copy it back.

IF YOU GET STUCK
  - Re-read the step in the Lab Instructions you are on.
  - Copy the exact red error message and paste it to Claude together with
    your full code. Say you are a beginner and ask it to explain simply.
  - "File not found" errors almost always mean a file is in the wrong
    place or has a different name. Check that it sits next to your code
    and that the spelling matches exactly.
  - In this lab, errors are the point. Read each error message before
    asking Claude about it: what type of error is it, and which line
    does it point to?
